## 🌟 Overview

**AI Traffic V25** is an advanced adaptive traffic control system (ATCS) simulation designed to maintain ultra-smooth, free-flowing traffic at urban intersections. By leveraging proactive sensor logic and a Reinforcement Learning kernel, the system dynamically manages traffic signal phases to prevent congestion, limiting vehicle queues to a maximum of 2–3 cars per approach.

---

## ✨ Key Features

- **🧠 Proactive Neural ATCS:** Uses Q-Learning to anticipate traffic buildup and prevent gridlocks.
- **🚗 Balanced Micro-Sparse Flow:** Calibrated injection rates and anti-lock safety timers ensure streets remain clear.
- **🛑 Zero-Collision Protocol:** Strict intersection management prevents vehicle and pedestrian conflicts.
- **🚶 Integrated Pedestrian Crossing:** Dynamic signal phases safely handle crosswalk pedestrians.
- **📊 Automated Engineering Reports:** Automatically exports performance data into `traffic_simulation_report.csv` upon exit.
